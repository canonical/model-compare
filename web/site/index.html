OpenCode v2 — model-compare plugin

(OpenCode v2 has no --model for TUI launches.) Add the plugin to opencode.jsonc (project or global): 

{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    {
      "package": "model-compare-opencode-plugin",
      "options": { "source": "auto", "defaultPriority": "balanced" }
    }
  ]
}

It registers three aliases in the model picker — model-compare/balanced, /price, /quality — always resolving to the current best. Point your default at one, or switch any session with /use-best. For options, keyboard shortcuts, weights, and pins, see model-compare-opencode-plugin on GitHub.
